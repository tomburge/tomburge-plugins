# tomburge-plugins

Claude Code plugins made by Tom Burge.

## Add the marketplace

```text
/plugin marketplace add tomburge/tomburge-plugins
```

## Plugins

| Plugin | Description | Install |
| --- | --- | --- |
| [tomdlc](plugins/tomdlc/README.md) | A secure software delivery lifecycle: the seven SDLC stages with DevOps, DevSecOps and NIST SSDF practices, run by an orchestrator that dispatches specialist agents. | `/plugin install tomdlc@tomburge-plugins` |

On Claude Code 2.1.275 or later, you can add the marketplace and install a plugin in one step:

```text
/plugin install tomdlc --marketplace tomburge/tomburge-plugins
```
